# Gather & Co. Events

ISM 6225, Assignment 1 (Look and Feel). Content theme: **Event Planner**.

Live site: https://dhivyav-usf.github.io/event-planning/

A static website for a fictional Dallas event planning company that plans weddings, corporate events, and birthday/social parties. All event data and testimonials are sample data. Photos are free stock images.

## Pages

| Page | File | What it does |
| --- | --- | --- |
| Home | `index.html` | Overview of the company, event types, planning process, photo gallery, testimonials, and upcoming events |
| Manage Events | `manageevents.html` | Mock CRUD: add, search/filter, edit, and delete events (data resets on reload) |
| Analytics | `analytics.html` | Chart.js charts of events by type, monthly revenue, and revenue share by type |
| About Us | `aboutus.html` | Developer profile, how the site was built, and technologies used |
