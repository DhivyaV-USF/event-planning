BEHIND THE BUILD

How I built
this website.

I built the site in Visual Studio Code using the folder structure from the class starter repository: the HTML pages at the top level, with separate folders for CSS, JavaScript, and images. I used AI prompts to generate one page at a time, starting with the home page and shared stylesheet so every page would use the same menu and look.

The Manage Events page mocks create, read, update, and delete operations with JavaScript. Events are kept in a JavaScript array, so you can add, search, filter, edit, and delete them, and the data resets when the page reloads. The Analytics page uses Chart.js to show sample event data by type, by month, and by revenue share.

After the first version, I reviewed and tested every page and made fixes: I resized my profile photo from over 5 MB to about 30 KB so the page loads quickly, made the text larger and easier to read, and changed the events table to show as cards on phones so the Edit and Delete buttons are always visible.

I also looked at how real event planner websites are designed. Most lead with photography, organize their work by event type, and build trust with client testimonials, so I added free stock photos to the home page, a gallery of event details, and a sample testimonials section. Each photo is cropped and compressed to under 115 KB, and the gallery photos load only when you scroll to them.

The biggest lesson for me was that generating code is only the first step. Testing on different screen sizes, checking file names (GitHub Pages is case-sensitive), and keeping files small made the difference between a page that looks good on my laptop and one that works well for everyone.
